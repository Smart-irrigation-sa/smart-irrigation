# مساعد الري الذكي

نموذج تصوّري تفاعلي لمشروع **نظام الري الذاتي الذكي لمراقبة رطوبة التربة وإدارة خزانات المزارع والحدائق**.

- **إعداد الطالب الباحث:** محمد دخيل الله المطيري
- **إشراف التصنيع الرقمي:** م. سامي بخش (معمل شهم)
- **الإشراف العلمي والتربوي:** د. أحمد محمود التوني (مدارس القلعة الحجازية)

## التشغيل
- عبر الإنترنت: https://abeer201-ux.github.io/smart-irrigation/
- دون إنترنت: افتح `index.html` مباشرة في المتصفح.

## ملاحظات
- جميع القراءات في الواجهة بيانات محاكاة لتوضيح طريقة عمل النظام.
- طبقة الذكاء الاصطناعي تطوير مقترح واستشاري فقط. لربط المساعد بـ Claude، ضع رابط الخادم الوسيط في `AI_ENDPOINT` داخل `index.html`. مفتاح API لا يوضع في هذا المستودع أبدًا.
